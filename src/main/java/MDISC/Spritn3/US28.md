## US27 – Shortest Route Through Specified Stations

### Objective

Given a scenario with stations and railway lines, determine the shortest route between two stations, passing through a user-specified list of intermediate stations (checkpoints), in the defined order.

---

### Method 1: `shortestPath(Station origin, Station destination)`

This method implements a simplified Dijkstra's algorithm using linear search to find the unvisited node with the smallest tentative distance.

#### Java Code:

```text
FUNCTION shortestPath(origin, destination):
    stations ← list of all stations
    lines ← list of all lines
    n ← size of stations
    dist[n] ← ∞
    visited[n] ← false
    prev[n] ← -1

    dist[origin] ← 0

    FOR count ← 0 TO n - 1:
        u ← station with min dist and not visited
        IF u = -1: BREAK
        visited[u] ← true

        FOR each line in lines:
            IF u is connected to neighbor:
                v ← index of neighbor
                IF NOT visited[v]:
                    weight ← line.length
                    IF dist[u] + weight < dist[v]:
                        dist[v] ← dist[u] + weight
                        prev[v] ← u

    IF dist[destination] = ∞: RETURN null

    path ← empty list
    at ← destination
    WHILE at ≠ -1:
        insert stations[at] at beginning of path
        at ← prev[at]

    RETURN path
```

#### Complexity Table (Line-by-Line Analysis)

| Block | Action                                   | Repetitions         | Cost per rep | Total Cost |
|-------|------------------------------------------|----------------------|--------------|------------|
| 1     | Initialize arrays                        | n                   | O(1)         | O(n)       |
| 2     | Search for station indexes               | n                   | O(n)         | O(n)       |
| 3     | Outer loop for unvisited node (n times)  | n                   | O(n)         | O(n²)      |
| 4     | Inner loop over all lines                | m                   | O(1)         | O(m)       |
| 5     | Index lookup for neighbors               | ≤ m                 | O(n)         | O(m·n)     |
| 6     | Update distances                         | ≤ m                 | O(1)         | O(m)       |
| 7     | Reconstruct path                         | ≤ n                 | O(1)         | O(n)       |
|       | **Total**                                |                      |              | **O(n² + m·n)** |

> In practice, since m ≤ n², we can simplify to **O(n²)** for this method.

### Method 2: `getShortestRouteThrough(Station start, List<Station> checkpoints, Station end)`

This method chains multiple shortest paths between consecutive points in the ordered list: `start -> checkpoint1 -> ... -> end`.

#### Java Code:

```text
FUNCTION getShortestRouteThrough(start, checkpoints, end):
    fullPath ← empty list
    allPoints ← [start] + checkpoints + [end]

    FOR i ← 0 TO size(allPoints) - 2:
        from ← allPoints[i]
        to ← allPoints[i + 1]

        segment ← shortestPath(from, to)
        IF segment is null or empty: RETURN null

        IF fullPath is not empty: remove first element from segment
        append all of segment to fullPath

    RETURN fullPath
```

#### Complexity Table (Line-by-Line Analysis)

| Line | Action                                       | Repetitions         | Cost per rep | Total Cost       |
|------|----------------------------------------------|----------------------|--------------|------------------|
| 1–3  | Build list with start, checkpoints, end      | k                   | O(1)         | O(k)             |
| 4–11 | Loop over k+1 pairs and call shortestPath    | k+1                 | O(n² + m)    | O(k·(n² + m))     |
| 7     | Merge and remove duplicates                 | k                   | O(n)         | O(k·n)           |
|      | **Total**                                    |                      |              | **O(k·n²)**       |

---

### Summary

| Method                      | Time Complexity        |
|----------------------------|------------------------|
| `shortestPath`             | O(n² + m)              |
| `getShortestRouteThrough`  | O(k·n²)                |

> The current implementation is a simplified Dijkstra without a heap, so complexity is quadratic.  
> For improved performance, a min-heap (priority queue) would reduce `shortestPath` to **O((n + m) log n)**.
