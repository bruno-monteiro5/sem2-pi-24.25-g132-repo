# US14 – Maintenance Route Through All Lines

## Objective

Given a railway network, determine whether it is possible to follow a route that passes **exactly once through every railway line**, and return the corresponding route if it exists. This corresponds to finding an **Eulerian trail** in an undirected graph.

---

## Problem Type

This problem is modeled as a **graph traversal problem** and is solved using the classical **Fleury’s Algorithm**.

---

## Theoretical Background (Discrete Mathematics)

This user story relies on **graph theory** concepts covered in the Discrete Mathematics course:

### Eulerian Trail Conditions

A **connected undirected graph** has an **Eulerian trail** (a path that uses every edge exactly once) if:

- The graph is **connected** (all vertices reachable from any starting point)
- It has **exactly 0 or 2 vertices with odd degree**.

If:
- 0 vertices have odd degree → Eulerian **cycle** (can start and end anywhere)
- 2 vertices have odd degree → Eulerian **path** (must start and end at those two)
- More than 2 → no Eulerian path exists

---

## Method: `findEulerianPath(...)`

### Inputs:
- `boolean onlyElectrified`: whether to include only electrified lines (`true`) or all (`false`)

### Steps:

1. **Filter lines** based on the flag:
    - Include only electrified lines (if requested)

2. **Build the induced subgraph**:
    - Create a list of all connected stations
    - Construct the **adjacency matrix** `adj[i][j] = number of lines between i and j`

3. **Check connectivity using DFS**:
    - Run a primitive DFS on the matrix
    - If any station is unreachable, the graph is not connected

4. **Count vertices with odd degree**:
    - For each station, sum edges (degree)
    - Store odd-degree stations

5. **Decide how to start the trail**:
    - If there are 2 odd-degree vertices → ask user to choose which one to start from
    - If 0 → start from any

6. **Apply Fleury's algorithm**:
    - Recursively build the Eulerian trail
    - Remove edges as they are used

---

## Java Implementation (simplified)

```java
public void findEulerianPath(boolean onlyElectrified) {
    ArrayList<Station> subStations = new ArrayList<>();
    ArrayList<Line> subLines = new ArrayList<>();

    // Step 1: filter lines
    for (Line l : lines) {
        if (onlyElectrified && !l.isElectrified()) continue;
        subLines.add(l);
        if (!subStations.contains(l.getStationA())) subStations.add(l.getStationA());
        if (!subStations.contains(l.getStationB())) subStations.add(l.getStationB());
    }

    int n = subStations.size();
    int[][] adj = new int[n][n];

    // Step 2: build adjacency matrix
    for (Line l : subLines) {
        int i = subStations.indexOf(l.getStationA());
        int j = subStations.indexOf(l.getStationB());
        adj[i][j]++;
        adj[j][i]++;
    }

    // Step 3: check connectivity
    boolean[] visited = new boolean[n];
    dfs(adj, 0, visited);
    for (boolean v : visited) {
        if (!v) {
            System.out.println("Graph not connected.");
            return;
        }
    }

    // Step 4: count odd-degree vertices
    ArrayList<Integer> oddVertices = new ArrayList<>();
    for (int i = 0; i < n; i++) {
        int degree = 0;
        for (int j = 0; j < n; j++) degree += adj[i][j];
        if (degree % 2 != 0) oddVertices.add(i);
    }

    if (oddVertices.size() != 0 && oddVertices.size() != 2) {
        System.out.println("Graph has no Eulerian path.");
        return;
    }

    // Step 5: choose starting point
    int start = (oddVertices.size() == 2) ? oddVertices.get(0) : 0;

    // Step 6: Fleury's algorithm
    List<String> route = new ArrayList<>();
    fleury(adj, subStations, start, route);
    for (int i = 0; i < route.size(); i++) {
        System.out.print(route.get(i));
        if (i != route.size() - 1) System.out.print(" -> ");
    }
    System.out.println();
}
```

### Fleury’s Algorithm (Java Implementation)

This function recursively builds the Eulerian path by choosing edges one by one and removing them from the graph as they are traversed.

```java
private void fleury(int[][] adj, List<Station> stations, int u, List<String> route) {
    for (int v = 0; v < adj.length; v++) {
        if (adj[u][v] > 0) {
            // Step 1: Remove the edge (u, v) from the graph
            adj[u][v]--;
            adj[v][u]--;

            // Step 2: Recursively continue from vertex v
            fleury(adj, stations, v, route);
        }
    }

    // Step 3: Once no more edges can be followed from u, add it to the route
    route.add(0, stations.get(u).getName());
}
```
