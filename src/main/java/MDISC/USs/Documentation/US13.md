# US13 – Can a Train Travel Between Two Stations?

## Objective

This feature verifies whether a given train (steam, diesel, or electric) can travel between two stations in the railway network, respecting restrictions based on train type and line electrification.

---

## Context and Mathematical Foundations

The problem is modeled as a **graph**, where:

- **Vertices (V)** represent stations.
- **Edges (E)** represent railway lines (which may be electrified or not).
- The connectivity between stations depends on whether a path exists under constraints — a core concept in **Discrete Mathematics**.

### Relevant concepts from Discrete Mathematics (MDISC):

- **Undirected graphs**
- **Relations and connectivity**
- **Adjacency matrices**
- **Path existence (walks in a graph)**

All implementations strictly use **primitive operations**, as required by the project and by the MDISC course constraints.

---

## Method 1: `canTravel(...)`

### Purpose

This method checks whether a specific train can travel between **any two stations**, considering:

- **Electric** trains can only use **electrified** lines.
- **Steam** and **Diesel** trains can use all lines.

### Algorithm Steps

1. Filter railway lines based on train type.
2. Build an **adjacency matrix** `adj[i][j] = 1` if a valid connection exists.
3. Use **BFS-style propagation** with a `visited[]` array to test reachability.
4. Return `true` if the destination station becomes visited.

### Mathematical Description

Let `G = (V, E)` be the subgraph induced by valid lines.

We define a **binary relation** R such that:
- `(u, v) ∈ R ⇔` there exists a valid line between station `u` and station `v`.

We construct the **adjacency matrix** `A` for `R` and compute whether a **path** exists from `u` to `v` using a closure over the graph via primitive BFS.

```java
public boolean canTravel(String from, String to, String trainType) {
    int[][] adj = buildAdjacencyMatrix(trainType); // based on train type
    int fromIndex = indexOf(from);

    boolean[] visited = new boolean[n];

    visited[fromIndex] = true;
    boolean changed;

    do {
        changed = false;
        for (int i = 0; i < n; i++) {
            if (visited[i]) {
                for (int j = 0; j < n; j++) {
                    if (adj[i][j] == 1 && !visited[j]) {
                        visited[j] = true;
                        changed = true;
                    }
                }
            }
        }
    } while (changed);

    return visited[toIndex];
}
```

## Method 2: `isTypeFullyConnected(...)`

### Purpose

Checks whether **all stations of a specific type** (`Depot`, `Station`, or `Terminal`) are reachable from one another, based on the constraints of a selected train type (`steam`, `diesel`, or `electric`).

This function ensures **full connectivity** within a filtered subset of the railway network.

---

### Algorithm Steps

1. **Filter stations by type**:
    - Create a list `filtered[]` with only stations starting with `D_`, `S_`, or `T_`.

2. **Filter lines** according to train type:
    - `electric` → only electrified lines
    - `steam` and `diesel` → all lines

3. **Build adjacency matrix** `adj[i][j] = 1`:
    - If a valid connection exists between stations `i` and `j`, mark it.

4. **Apply primitive DFS traversal**:
    - Start from any station
    - Mark all reachable ones using a boolean array `visited[]`

5. **Verify if all filtered stations are reachable**:
    - If any `visited[i] == false`, then the graph is not fully connected

---

### Mathematical Discrete Concepts (MDISC)

This method uses fundamental concepts from **graph theory**:

- We define a **binary relation** of reachability between stations of a given type.
- This relation is represented via an **adjacency matrix**.
- We test the **connectivity** of the subgraph `G' = (V', E')`, where:
    - `V'` is the set of all stations of the selected type
    - `E'` is the set of valid edges between them (based on train constraints)

The connectivity test is implemented with **primitive DFS traversal** only, following restrictions of the MDISC course.

---

### Java Code Snippet (Simplified)

```java
public boolean isTypeFullyConnected(String trainType, String stationTypeString) {
    char stationType = stationTypeString.toUpperCase().charAt(0);
    ArrayList<Station> filtered = new ArrayList<>();

    // Step 1: Filter stations of the given type
    for (Station s : stations) {
        if (s.getType() == stationType) {
            filtered.add(s);
        }
    }

    int n = filtered.size();
    if (n <= 1) return true; // Trivially connected

    int[][] adj = new int[n][n];

    // Step 2 & 3: Build adjacency matrix for filtered stations
    for (Line l : lines) {
        Station a = l.getStationA();
        Station b = l.getStationB();
        if (a.getType() != stationType || b.getType() != stationType) continue;

        boolean useLine = trainType.equalsIgnoreCase("electric") ? l.isElectrified() :
                          trainType.equalsIgnoreCase("steam") || trainType.equalsIgnoreCase("diesel");

        if (!useLine) continue;

        int i = filtered.indexOf(a);
        int j = filtered.indexOf(b);
        if (i >= 0 && j >= 0) {
            adj[i][j] = 1;
            adj[j][i] = 1;
        }
    }

    // Step 4: DFS traversal
    boolean[] visited = new boolean[n];
    dfsType(adj, 0, visited);

    // Step 5: Check full connectivity
    for (boolean v : visited) {
        if (!v) return false;
    }
    return true;
}

// Helper method for DFS
private void dfsType(int[][] matrix, int i, boolean[] visited) {
    visited[i] = true;
    for (int j = 0; j < matrix.length; j++) {
        if (matrix[i][j] == 1 && !visited[j]) {
            dfsType(matrix, j, visited);
        }
    }
}
```
