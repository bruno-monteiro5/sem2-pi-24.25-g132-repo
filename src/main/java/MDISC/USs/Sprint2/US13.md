# US13 – Can a Train Travel Between Two Stations?

## Objective

This feature verifies whether a given train (steam, diesel, or electric) can travel between two stations in the railway network, respecting restrictions based on train type and line electrification.

---

## Context and Mathematical Foundations

The problem is modeled as a **graph**, where:

- **Vertices (V)** represent stations.
- **Edges (E)** represent railway lines (which may be electrified or not).
- The connectivity between stations depends on whether a path exists under constraints — a core concept in **Discrete Mathematics**.

### Relevant concepts from Discrete Mathematics (MDISC):

- **Undirected graphs**
- **Relations and connectivity**
- **Adjacency matrices**
- **Path existence (walks in a graph)**

All implementations strictly use **primitive operations**, as required by the project and by the MDISC course constraints.

---

## Method 1: `canTravel(...)`

### Purpose

This method checks whether a specific train can travel between **any two stations**, considering:

- **Electric** trains can only use **electrified** lines.
- **Steam** and **Diesel** trains can use all lines.

### Algorithm Steps

1. Filter railway lines based on train type.
2. Build an **adjacency matrix** `adj[i][j] = 1` if a valid connection exists.
3. Use **BFS-style propagation** with a `visited[]` array to test reachability.
4. Return `true` if the destination station becomes visited.

### Mathematical Description

Let `G = (V, E)` be the subgraph induced by valid lines.

We define a **binary relation** R such that:
- `(u, v) ∈ R ⇔` there exists a valid line between station `u` and station `v`.

We construct the **adjacency matrix** `A` for `R` and compute whether a **path** exists from `u` to `v` using a closure over the graph via primitive BFS.

```java
            }
        }
    } while (changed);

    return visited[toIndex];
}
```

## Method 2: `isTypeFullyConnected(...)`

### Objective

Verify whether all stations of a given type (`Depot`, `Station`, or `Terminal`) are fully connected using a specific type of train (`steam`, `diesel`, or `electric`), **even if the path passes through stations of other types**.

---

### Problem Context

This is a **graph connectivity** problem with edge restrictions based on the type of train:

- **Steam** and **Diesel** trains can use all railway lines.
- **Electric** trains can only use **electrified** lines.

---

### Graph Model

- **Vertices (nodes)**: all stations from the railway network.
- **Edges (connections)**: railway lines allowed for the selected train type.
- The graph is **undirected**.

We use a **matrix of adjacency** (`int[][]`) to represent connections between stations.

---

### Algorithm Description

1. **Build the full graph:**
    - All stations are included.
    - Only the railway lines allowed for the selected train type are considered when filling the adjacency matrix.

2. **For each station of the selected type:**
    - Run a **propagation algorithm** (DFS-like using primitives) starting from this station.

3. **Check whether all other stations of the same type were visited:**
    - If yes, that means all stations of the same type are connected (via any valid path).
    - If any is unreachable, return false.

---


### Java Code Snippet (Simplified)

```java
public boolean isTypeFullyConnected(String trainType, String stationTypeStr) {
    char stationType = stationTypeStr.toUpperCase().charAt(0); // 'D', 'S', 'T'
    ArrayList<Station> filteredStations = new ArrayList<>();
    for (Station s : stations) {
        if (s.getType() == stationType) {
            filteredStations.add(s);
        }
    }

    int n = stations.size();
    int[][] adj = new int[n][n];

    // Construir matriz de adjacência com todas as estações e linhas válidas
    for (Line l : lines) {
        boolean useLine = trainType.equalsIgnoreCase("electric") ? l.isElectrified()
                : trainType.equalsIgnoreCase("steam") || trainType.equalsIgnoreCase("diesel");

        if (!useLine) continue;

        int i = stations.indexOf(l.getStationA());
        int j = stations.indexOf(l.getStationB());
        if (i >= 0 && j >= 0) {
            adj[i][j] = 1;
            adj[j][i] = 1;
        }
    }

    // Testar conectividade entre todos os pares do mesmo tipo
    for (int a = 0; a < filteredStations.size(); a++) {
        Station start = filteredStations.get(a);
        int startIndex = stations.indexOf(start);

        boolean[] visited = new boolean[n];
        visited[startIndex] = true;
        boolean changed;

        do {
            changed = false;
            for (int i = 0; i < n; i++) {
                if (visited[i]) {
                    for (int j = 0; j < n; j++) {
                        if (adj[i][j] == 1 && !visited[j]) {
                            visited[j] = true;
                            changed = true;
                        }
                    }
                }
            }
        } while (changed);

        // Verificar se todas as outras do mesmo tipo foram visitadas
        for (int b = 0; b < filteredStations.size(); b++) {
            if (a == b) continue;
            Station target = filteredStations.get(b);
            int targetIndex = stations.indexOf(target);
            if (!visited[targetIndex]) {
                return false;
            }
        }
    }

    return true;
}
```
