## US13 – Can a Train Travel Between Two Stations?

### Objective
Determine if a train of a given type (steam, diesel, electric) can travel between two stations.

---

### Algorithm 1: `canTravel(from, to, trainType)`

#### Pseudocode
```
DS: INT i, j, fromIndex, toIndex, n
    MATRIX[INT] adj
    ARRAY[INT] visited
    BOOLEAN changed
BEGIN
1. n <- total number of stations
2. Create adj[n][n] and initialize all entries to 0
3. FOR each line in lines DO
4.     IF trainType = "electric" AND line not electrified THEN
5.         Skip this line
6.     ELSE
7.         i <- index of line.stationA
8.         j <- index of line.stationB
9.         adj[i][j] <- 1
10.        adj[j][i] <- 1
11. ENDFOR
12. fromIndex <- index of station "from"
13. toIndex <- index of station "to"
14. visited[fromIndex] <- true
15. WHILE changed is true DO
16.     changed <- false
17.     FOR i from 0 to n-1 DO
18.         IF visited[i] THEN
19.             FOR j from 0 to n-1 DO
20.                 IF adj[i][j] = 1 AND NOT visited[j] THEN
21.                     visited[j] <- true
22.                     changed <- true
23. ENDWHILE
24. RETURN visited[toIndex]
END
```

#### Complexity Table (Line-by-Line Analysis)

| Line | Action                                   | Repetitions | Cost per rep | Total Cost |
|------|------------------------------------------|-------------|--------------|------------|
| 1    | Store number of stations                 | 1           | 1            | O(1)       |
| 2    | Initialize matrix adj\[n]\[n]            | 1           | O(n²)        | O(n²)      |
| 3    | Start iteration over lines               | 1           | —            | —          |
| 4    | Check if line is disallowed for electric | m           | 1            | O(m)       |
| 5    | Skip line (if disallowed)                | ≤ m         | 1            | O(m)       |
| 6    | Else branch entered                      | ≤ m         | —            | —          |
| 7    | Get index of station A                   | ≤ m         | O(n)         | O(m·n)     |
| 8    | Get index of station B                   | ≤ m         | O(n)         | O(m·n)     |
| 9    | Set adj\[i]\[j] = 1                      | ≤ m         | 1            | O(m)       |
| 10   | Set adj\[j]\[i] = 1                      | ≤ m         | 1            | O(m)       |
| 11   | End FOR                                  | 1           | —            | —          |
| 12   | Get index of 'from' station              | 1           | O(n)         | O(n)       |
| 13   | Get index of 'to' station                | 1           | O(n)         | O(n)       |
| 14   | Mark 'from' as visited                   | 1           | 1            | O(1)       |
| 15   | Start WHILE loop                         | ≤ n         | —            | —          |
| 16   | Reset change flag                        | ≤ n         | 1            | O(n)       |
| 17   | Outer loop over stations                 | ≤ n         | 1            | O(n)       |
| 18   | Check if station was visited             | ≤ n         | 1            | O(n)       |
| 19   | Inner loop over all stations             | ≤ n × n     | 1            | O(n²)      |
| 20   | Check adjacency and not visited          | ≤ n²        | 1            | O(n²)      |
| 21   | Mark station as visited                  | ≤ n²        | 1            | O(n²)      |
| 22   | Set changed to true                      | ≤ n²        | 1            | O(n²)      |
| 23   | End WHILE                                | —           | —            | —          |
| 24   | Return visited\[toIndex]                 | 1           | 1            | O(1)       |
|      | **Total**                                |             |              | **O(n²)**  |

### Algorithm 2: `isTypeFullyConnected(trainType, stationType)`

#### Pseudocode
```
DS: INT i, j, a, b, n
    MATRIX[INT] adj
    ARRAY[BOOLEAN] visited
    ARRAY[Station] filtered
    BOOLEAN changed
    CHAR type
    
BEGIN
1. n <- number of stations
2. filtered <- stations of given type
3. Create adj[n][n] initialized to 0
4. FOR each line in lines DO
5.     IF line allowed for trainType THEN
6.         i <- index of line.stationA
7.         j <- index of line.stationB
8.         adj[i][j] <- 1
9.         adj[j][i] <- 1
10. ENDFOR
11. FOR a from 0 to |filtered|-1 DO
12.     visited[n] <- false
13.     visited[index(filtered[a])] <- true
14.     WHILE changed is true DO
15.         changed <- false
16.         FOR i from 0 to n-1 DO
17.             IF visited[i] THEN
18.                 FOR j from 0 to n-1 DO
19.                     IF adj[i][j] = 1 AND NOT visited[j] THEN
20.                         visited[j] <- true
21.                         changed <- true
22.     ENDWHILE
23.     FOR b from 0 to |filtered|-1 DO
24.         IF NOT visited[index(filtered[b])] THEN
25.             RETURN false
26. ENDFOR
27. RETURN true
END
```

| Line | Action                              | Repetitions | Cost per rep | Total Cost    |
|------|-------------------------------------|-------------|--------------|---------------|
| 1    | Store number of stations            | 1           | 1            | O(1)          |
| 2    | Filter stations of given type       | n           | 1            | O(n)          |
| 3    | Initialize matrix adj\[n]\[n]       | 1           | O(n²)        | O(n²)         |
| 4    | Start line iteration                | 1           | —            | —             |
| 5    | Check train type condition          | m           | 1            | O(m)          |
| 6    |                                     |             |              |               |
| 7    | Get index of line.stationA          | ≤ m         | O(n)         | O(m·n)        |
| 8    | Get index of line.stationB          | ≤ m         | O(n)         | O(m·n)        |
| 9    | Fill adj\[i]\[j] and adj\[j]\[i]    | ≤ m         | 1            | O(m)          |
| 10   | End FOR                             | 1           | —            | —             |
| 11   | Loop over filtered stations         | T           | —            | —             |
| 12   | Reset visited array                 | T           | O(n)         | O(T·n)        |
| 13   | Mark one visited                    | T           | 1            | O(T)          |
| 14   | Start WHILE loop                    | T × ≤n      | —            | —             |
| 15   | Reset change                        | T × ≤n      | 1            | O(T·n)        |
| 16   | Outer loop over stations            | T × n       | 1            | O(T·n)        |
| 17   | Check if station is visited         | T × n       | 1            | O(T·n)        |
| 18   | Inner loop                          | T × n × n   | 1            | O(T·n²)       |
| 19   | Check adjacency and not visited     | T × n × n   | 1            | O(T·n²)       |

| 22   | End WHILE                           | —           | —            | —             |

## US14 – Maintenance Route Through All Lines

### Objective

Given a railway network, determine whether it is possible to follow a route that passes **exactly once through every railway line**, and return the corresponding route if it exists. This corresponds to finding an **Eulerian trail** in an undirected graph.

---


### Algorithm 3: `findEulerianPath(onlyelectrified)`

#### Pseudocode
```
DS: INT i, j, n, degree, start
    STRING option
    MATRIX[INT] adj
    ARRAY[Station] subStations
    ARRAY[Line] subLines
    ARRAY[BOOLEAN] visited
    ARRAY[INT] oddVertices
    SCANNER scanner
    LIST[STRING] route

BEGIN
1. subLines <- lines filtered according to onlyElectrified
2. subStations <- stations present in subLines
3. n <- size of subStations
4. Initialize adj[n][n] with 0
5. FOR each line l in subLines DO
6.     i <- index of l.stationA in subStations
7.     j <- index of l.stationB in subStations
8.     adj[i][j]++
9.     adj[j][i]++
10. visited[n] <- false
11. Call dfs(adj, 0, visited)
12. FOR each v in visited DO
13.     IF v = false THEN
14.         print "Graph isn't connected."
15.         return
16. oddVertices <- []
17. FOR i from 0 to n-1 DO
18.     degree <- sum of adj[i][j] for j = 0 to n-1
19.     IF degree % 2 ≠ 0 THEN add i to oddVertices
20. IF size(oddVertices) ≠ 0 AND ≠ 2 THEN
21.     print "Graph doesn't have an Eulerian path."
22.     return
23. IF size(oddVertices) = 2 THEN
24.     print info about both odd-degree stations
25.     prompt user input (1 or 2)
26.     IF option = "1" THEN start <- oddVertices[0]
27.     ELSE IF option = "2" THEN start <- oddVertices[1]
28.     ELSE start <- oddVertices[0]
29. ELSE
30.     start <- 0
31.     print "The graph has an Eulerian cycle..."
32. print "Calculating maintenance route..."
33. route <- []
34. Call fleury(adj, subStations, start, route)
35. FOR i from 0 to size(route) - 1 DO
36.     print route[i]
37.     IF i ≠ last THEN print " -> "
END
```

#### Complexity Table (Line-by-Line Analysis)

| Line | Action                               | Repetitions | Cost per rep | Total Cost |
|------|--------------------------------------|-------------|--------------|------------|
| 1    | Filter lines                         | m           | 1            | O(m)       |
| 2    | Get stations from filtered lines     | m           | 1            | O(m)       |
| 3    | Get number of subStations            | 1           | 1            | O(1)       |
| 4    | Initialize adjacency matrix          | 1           | O(n²)        | O(n²)      |
| 5    | Start iteration over subLines        | 1           | —            | —          |
| 6    | Get index of stationA                | m           | O(n)         | O(m·n)     |
| 7    | Get index of stationB                | m           | O(n)         | O(m·n)     |
| 8    | Increment adj\[i]\[j]                | m           | 1            | O(m)       |
| 9    | Increment adj\[j]\[i]                | m           | 1            | O(m)       |
| 10   | End FOR                              | 1           | —            | —          |
| 11   | Initialize visited array             | 1           | O(n)         | O(n)       |
| 12   | Call DFS                             | ≤ n         | O(n)         | O(n²)      |
| 13   | Loop to check if graph is connected  | n           | 1            | O(n)       |
| 14   | Check if node was visited            | n           | 1            | O(n)       |
| 15   | Return if disconnected               | ≤ 1         | 1            | O(1)       |
| 16   | Create oddVertices list              | 1           | 1            | O(1)       |
| 17   | Start loop to compute degrees        | n           | —            | —          |
| 18   | Sum of degrees in row                | n           | O(n)         | O(n²)      |
| 19   | Check if degree is odd               | n           | 1            | O(n)       |
| 20   | Add to oddVertices                   | ≤ n         | 1            | O(n)       |
| 21   | Check number of odd vertices         | 1           | 1            | O(1)       |
| 22   | Return if not valid                  | ≤ 1         | 1            | O(1)       |
| 23   | Check if oddVertices.size == 2       | 1           | 1            | O(1)       |
| 24   | Print info about odd vertices        | 1           | 1            | O(1)       |
| 25   | Prompt user input                    | 1           | 1            | O(1)       |
| 26   | Check input == "1"                   | 1           | 1            | O(1)       |
| 27   | Check input == "2"                   | 1           | 1            | O(1)       |
| 28   | Default to first option              | 1           | 1            | O(1)       |
| 29   | Set default start for Eulerian cycle | 1           | 1            | O(1)       |
| 30   | Assign start = 0                     | 1           | 1            | O(1)       |
| 31   | Print cycle message                  | 1           | 1            | O(1)       |
| 32   | Print Fleury header                  | 1           | 1            | O(1)       |
| 33   | Initialize route list                | 1           | 1            | O(1)       |
| 34   | Call Fleury traversal                | ≤ m         | O(m)         | O(m²)      |
| 35   | Start loop to print route            | m           | 1            | O(m)       |
| 36   | Print station name                   | m           | 1            | O(m)       |
| 37   | Print "->" separator if needed       | ≤ m         | 1            | O(m)       |
|      | **Total**                            |             |              | **O(m²)**  |

### Algorithm 4: `fleury((adj, stations, u, route))`

#### Pseudocode
```
DS: INT v, u
    MATRIX[INT] adj
    LIST[Station] stations
    LIST[STRING] route

BEGIN
1. FOR v from 0 to adj.length - 1 DO
2.     IF adj[u][v] > 0 THEN
3.         adj[u][v] <- adj[u][v] - 1
4.         adj[v][u] <- adj[v][u] - 1
5.         CALL fleury(adj, stations, v, route)
6.     ENDIF
7. ENDFOR
8. INSERT stations[u].name AT BEGINNING OF route
END
```
