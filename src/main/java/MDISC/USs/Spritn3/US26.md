## US13 – Can a Train Travel Between Two Stations?

### Objective
Determine if a train of a given type (steam, diesel, electric) can travel between two stations.

---

### Algorithm 1: `canTravel(from, to, trainType)`

#### Pseudocode
```
DS: INTEGER i, j, fromIndex, toIndex, n
    ARRAY[INTEGER] visited
    MATRIX[INTEGER] adj
    BOOLEAN changed
BEGIN
1. n <- total number of stations
2. Create adj[n][n] and initialize all entries to 0
3. FOR each line in lines DO
4.     IF trainType = "electric" AND line not electrified THEN
5.         Skip this line
6.     ELSE
7.         i <- index of line.stationA
8.         j <- index of line.stationB
9.         adj[i][j] <- 1
10.        adj[j][i] <- 1
11. ENDFOR
12. fromIndex <- index of station "from"
13. toIndex <- index of station "to"
14. visited[fromIndex] <- true
15. WHILE changed is true DO
16.     changed <- false
17.     FOR i from 0 to n-1 DO
18.         IF visited[i] THEN
19.             FOR j from 0 to n-1 DO
20.                 IF adj[i][j] = 1 AND NOT visited[j] THEN
21.                     visited[j] <- true
22.                     changed <- true
23. ENDWHILE
24. RETURN visited[toIndex]
END
```

#### Complexity Table (Line-by-Line Analysis)

| Line | Action                                   | Repetitions | Cost per rep | Total Cost |
|------|------------------------------------------|-------------|--------------|------------|
| 1    | Store number of stations                 | 1           | 1            | O(1)       |
| 2    | Initialize matrix adj\[n]\[n]            | 1           | O(n²)        | O(n²)      |
| 3    | Start iteration over lines               | 1           | —            | —          |
| 4    | Check if line is disallowed for electric | m           | 1            | O(m)       |
| 5    | Skip line (if disallowed)                | ≤ m         | 1            | O(m)       |
| 6    | Else branch entered                      | ≤ m         | —            | —          |
| 7    | Get index of station A                   | ≤ m         | O(n)         | O(m·n)     |
| 8    | Get index of station B                   | ≤ m         | O(n)         | O(m·n)     |
| 9    | Set adj\[i]\[j] = 1                      | ≤ m         | 1            | O(m)       |
| 10   | Set adj\[j]\[i] = 1                      | ≤ m         | 1            | O(m)       |
| 11   | End FOR                                  | 1           | —            | —          |
| 12   | Get index of 'from' station              | 1           | O(n)         | O(n)       |
| 13   | Get index of 'to' station                | 1           | O(n)         | O(n)       |
| 14   | Mark 'from' as visited                   | 1           | 1            | O(1)       |
| 15   | Start WHILE loop                         | ≤ n         | —            | —          |
| 16   | Reset change flag                        | ≤ n         | 1            | O(n)       |
| 17   | Outer loop over stations                 | ≤ n         | 1            | O(n)       |
| 18   | Check if station was visited             | ≤ n         | 1            | O(n)       |
| 19   | Inner loop over all stations             | ≤ n × n     | 1            | O(n²)      |
| 20   | Check adjacency and not visited          | ≤ n²        | 1            | O(n²)      |
| 21   | Mark station as visited                  | ≤ n²        | 1            | O(n²)      |
| 22   | Set changed to true                      | ≤ n²        | 1            | O(n²)      |
| 23   | End WHILE                                | —           | —            | —          |
| 24   | Return visited\[toIndex]                 | 1           | 1            | O(1)       |
|      | **Total**                                |             |              | **O(n²)**  |

### Algorithm 2: `isTypeFullyConnected(trainType, stationType)`

#### Pseudocode
```
DS: CHAR type
    ARRAY[Station] filtered
    MATRIX[INTEGER] adj
    BOOLEAN changed
    ARRAY[BOOLEAN] visited
    INTEGER i, j, a, b, n
BEGIN
1. n <- number of stations
2. filtered <- stations of given type
3. Create adj[n][n] initialized to 0
4. FOR each line in lines DO
5.     IF line allowed for trainType THEN
6.         i <- index of line.stationA
7.         j <- index of line.stationB
8.         adj[i][j] <- 1
9.         adj[j][i] <- 1
10. ENDFOR
11. FOR a from 0 to |filtered|-1 DO
12.     visited[n] <- false
13.     visited[index(filtered[a])] <- true
14.     WHILE changed is true DO
15.         changed <- false
16.         FOR i from 0 to n-1 DO
17.             IF visited[i] THEN
18.                 FOR j from 0 to n-1 DO
19.                     IF adj[i][j] = 1 AND NOT visited[j] THEN
20.                         visited[j] <- true
21.                         changed <- true
22.     ENDWHILE
23.     FOR b from 0 to |filtered|-1 DO
24.         IF NOT visited[index(filtered[b])] THEN
25.             RETURN false
26. ENDFOR
27. RETURN true
END
```

#### Complexity Table (Line-by-Line Analysis)

| Line | Action                              | Repetitions | Cost per rep | Total Cost    |
|------|-------------------------------------|-------------|--------------|---------------|
| 1    | Store number of stations            | 1           | 1            | O(1)          |
| 2    | Filter stations of given type       | n           | 1            | O(n)          |
| 3    | Initialize matrix adj\[n]\[n]       | 1           | O(n²)        | O(n²)         |
| 4    | Start line iteration                | 1           | —            | —             |
| 5    | Check train type condition          | m           | 1            | O(m)          |
| 6    |                                     |             |              |               |
| 7    | Get index of line.stationA          | ≤ m         | O(n)         | O(m·n)        |
| 8    | Get index of line.stationB          | ≤ m         | O(n)         | O(m·n)        |
| 9    | Fill adj\[i]\[j] and adj\[j]\[i]    | ≤ m         | 1            | O(m)          |
| 10   | End FOR                             | 1           | —            | —             |
| 11   | Loop over filtered stations         | T           | —            | —             |
| 12   | Reset visited array                 | T           | O(n)         | O(T·n)        |
| 13   | Mark one visited                    | T           | 1            | O(T)          |
| 14   | Start WHILE loop                    | T × ≤n      | —            | —             |
| 15   | Reset change                        | T × ≤n      | 1            | O(T·n)        |
| 16   | Outer loop over stations            | T × n       | 1            | O(T·n)        |
| 17   | Check if station is visited         | T × n       | 1            | O(T·n)        |
| 18   | Inner loop                          | T × n × n   | 1            | O(T·n²)       |
| 19   | Check adjacency and not visited     | T × n × n   | 1            | O(T·n²)       |
| 20   | Mark as visited                     | T × n × n   | 1            | O(T·n²)       |
| 21   | Set changed to true                 | T × n × n   | 1            | O(T·n²)       |
| 22   | End WHILE                           | —           | —            | —             |
| 23   | Loop over filtered to check visited | T × T       | 1            | O(T²)         |
| 24   | Check if visited                    | ≤ T         | 1            | O(T)          |
| 25   | Return false if not                 | ≤ T         | 1            | O(T)          |
| 26   | End FOR                             | 1           | —            | —             |
| 27   | Return true                         | 1           | 1            | O(1)          |
|      | **Total**                           |             |              | **O(T × n²)** |
