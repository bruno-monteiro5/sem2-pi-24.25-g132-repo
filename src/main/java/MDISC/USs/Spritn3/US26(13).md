# US13 – Can a Train Travel Between Two Stations?

## Objective
Determine if a train of a given type (steam, diesel, electric) can travel between two stations.

---

### Algorithm 1: `canTravel(from, to, trainType)`

#### Pseudocode
```
DS: INTEGER i, j, fromIndex, toIndex, n
    ARRAY[INTEGER] visited
    ARRAY[ARRAY[INTEGER]] adj
    BOOLEAN changed
BEGIN
n <- total number of stations
adj <- n x n matrix initialized to 0

FOR each line IN lines DO
    IF trainType = "electric" AND line is not electrified THEN
        CONTINUE
    ENDIF
    i <- index of line.stationA
    j <- index of line.stationB
    adj[i][j] <- 1
    adj[j][i] <- 1
ENDFOR

fromIndex <- index of from
toIndex <- index of to
visited[fromIndex] <- true

REPEAT
    changed <- false
    FOR i <- 0 TO n-1 DO
        IF visited[i] THEN
            FOR j <- 0 TO n-1 DO
                IF adj[i][j] = 1 AND NOT visited[j] THEN
                    visited[j] <- true
                    changed <- true
                ENDIF
            ENDFOR
        ENDIF
    ENDFOR
UNTIL NOT changed

RETURN visited[toIndex]
END
```
