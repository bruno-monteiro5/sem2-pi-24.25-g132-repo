# Glossary

**Terms, Expressions and Acronyms (TEA) must be organized alphabetically.**

Column "TEA (PT)" is optional. If the team does not intend to use it, then remove it.

(Complete according to the provided example)

| **_TEA_** (EN)              | **_Description_** (EN)                                                                                           |
|:----------------------------|:-----------------------------------------------------------------------------------------------------------------|
| **AC**                      | Acceptance Criteria                                                                                              |
| **City**                    | Populated area on the map with a name, coordinates and housing blocks                                            |
| **Editor**                  | Person who can create maps and scenarios that can be provided in a bundle with the game or sold separately       |
| **Historical Restriction**  | Historical events that make sense in the scenario and change to operating conditions of the simulator            |
| **Industry**                | Facility that generates or processes resources in the simulation                                                 |
| **Jacoco**                  | An open-source framework that measures how well automated tests exercise Java code                               |
| **Locomotive**              | Powered railway vehicle used for pulling trains                                                                  |
| **Mixed industry**          | Ports potentially have the capacity, depending on what is defined in the scenario, to import or export any cargo |
| **MVP**                     | Minimal Viable Product                                                                                           |
| **Player**                  | Person who wants to play a game                                                                                  |
| **Primary sector industry** | Generate resources, such as mines and farms                                                                      |
| **Product Owner**           | The person representing the organization that intends to develop the game                                        |
| **RailRoad Tycoon**         | Trains game that covers the areas of gameplay, economy and engineering                                           |
| **Railway line**            | Connection between two train stations                                                                            |
| **Route**                   | List of stations where the train passes                                                                          |
| **SVG**                     | Scalable Vector Graphics                                                                                         |
| **Time Restriction**        | The period in which the simulation will take place                                                               |
